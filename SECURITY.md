# Security

## Supported versions

We release fixes for security issues on the `main` branch and recommend running the latest published version.

## Reporting a vulnerability

**Please do not open a public GitHub issue for security vulnerabilities.**

Instead:

1. Use **[GitHub Security Advisories](https://github.com/jboho/dev-status/security/advisories)** (“Report a vulnerability”) if enabled for this repository, **or**
2. Contact the maintainers privately (repository owner / org admins listed on the GitHub repo).

Include:

- A short description of the issue and its impact
- Steps to reproduce (proof-of-concept if possible)
- Affected versions or commits, if known

We aim to acknowledge reports within a few business days and coordinate disclosure after a fix is available.

## Disclosure policy

Please give maintainers a reasonable window to ship a fix before public disclosure. We credit reporters who wish to be named in release notes or advisories.
